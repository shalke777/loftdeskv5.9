# LoftDesk v5.7 — Functional Recovery Patch

## Co poprawiono
- projekty: ręczny wybór dowolnego statusu, edycja także dla zakończonych, koszty projektu, generowanie faktury z projektu
- raporty: koszty projektów, budżety i marża
- kontrahenci: NIP, adres, kod pocztowy, osoba kontaktowa, pełna edycja
- kosztorysy: pełna edycja pozycji, statusu i terminu ważności
- faktury: pełna edycja do momentu wysyłki do KSeF, VAT per pozycja, rozbicie pozycji, transze z umowy, PDF/XML w podglądzie i pobraniu
- umowy: pełna edycja, własny formularz/szablon HTML z placeholderami, transze/raty, podgląd PDF
- backup: eksport / import JSON w ustawieniach
- dokumenty: pobieranie PDF/XML z modali podglądu

## Uwaga
Patch jest przygotowany na aktualną strukturę v5.6 i skupia się na brakach funkcjonalnych zgłoszonych po testach.
