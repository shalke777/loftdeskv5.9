# LoftDesk v5.2 final production runbook

1. Uruchom `npm run env:check`.
2. Uruchom `npm run deploy:ready`.
3. Uruchom `npm run go:live`.
4. Zrób snapshot bazy: `scripts/pre-cutover-snapshot.sql`.
5. Wdróż migracje `001` -> `016` w staging/prod zgodnie z kolejnością.
6. Zweryfikuj portal klienta, team invites, onboarding i billing.
7. Uruchom `scripts/post-cutover-verify.sql` oraz `scripts/rls-smoke.sql`.
8. Uruchom `npm run post:release:audit`.
9. Wypełnij `tests/manual/v5.2-final-production-checklist.md`.
10. Zostaw v3 jako fallback przez minimum 14 dni.

## Warunki wejścia
- owner/admin aktywny w workspace
- brak blokad w `/go-live`
- ustawione env produkcyjne
- snapshot danych zapisany

## Warunki wyjścia
- release verdict = production-ready albo świadomie zaakceptowane warnings
- portal i zaproszenia przechodzą smoke
- billing/settings/admin nie mają regresji
