# LoftDesk v4.3 — deliverables

## Zakres tej wersji
- usunięcie prowizorycznego hash-routera
- wdrożenie route tree pod TanStack Router
- rozbicie auth na osobne formularze i ekran publiczny
- dodanie workflow `estimate -> contract`
- rozbudowa ustawień o zarządzanie zespołem demo i profilem firmy
- poprawa portalu klienta pod trasę parametryczną `/portal/:token`
- zachowanie starego monolitu v3 jako referencji

## Co dalej naturalnie wynika z tej wersji
1. przepięcie feature po feature ze starego monolitu do nowych modułów
2. zastąpienie `demoDb` produkcyjnymi adapterami Supabase
3. dokończenie RLS per tabela zgodnie z migracjami 001-005
4. wygenerowanie `database.types.ts` bezpośrednio z projektu Supabase
5. dodanie testów E2E dla loginu, kosztorysów, faktur i portalu
