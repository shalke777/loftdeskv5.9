# LoftDesk v5.2 release gates

## Gates
- workspace bez blokad
- deploy checks bez blokad
- owner/admin prowadzi wydanie
- Supabase-first runtime gotowy lub świadomie zaakceptowany bridge mode
- cutover SQL pack obecny
- release docs i checklista obecne
- portal klienta objęty smoke

## Decyzja
- `blocked` -> brak zgody na go-live
- `warning` -> release review i świadoma akceptacja
- `ready` -> można przejść przez finalny cutover
