
# v5.1 Deploy-ready plan

1. Ustaw `.env` na stagingu (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_PUBLIC_BASE_URL`, `VITE_DATA_MODE=supabase`).
2. Odpal migracje SQL w kolejności 001 -> 014.
3. Zweryfikuj onboarding ownera, invite flow, portal i billing gating.
4. Uruchom skrypty:
   - `npm run env:check`
   - `npm run release:report`
   - `npm run deploy:ready`
   - `npm run smoke:routes`
5. Przejdź checklistę z `tests/manual/v5.1-deploy-ready-checklist.md`.
6. Dopiero po tym przechodź do v5.2 final cutover.
